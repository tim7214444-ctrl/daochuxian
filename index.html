常见问题

AI 助手显示“不能使用”？

道出锡安默认使用 Mac 自带的 Apple 智能，需要 macOS 26 或更新版本，并在“系统设置 → Apple 智能与 Siri”里打开 Apple 智能。也可以在“设置 → AI 账号”里改用自己的 Claude、ChatGPT 或 Grok（填入 API Key）。

怎样导入自己的书？

把 PDF、EPUB、Word、TXT、Markdown 或 HTML 文件拖进窗口，或在“书库”里点“导入”。

换电脑时资料怎么搬？

在“设置 → 完整备份”导出一个 zip，在新电脑上用“从完整备份恢复”导入即可。

我的资料会上传吗？

不会。所有书和笔记都只存在你的 Mac 上。详见 隐私政策。
